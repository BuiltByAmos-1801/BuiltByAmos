# Built By Amos Website

Static multi-page website for Built By Amos.

## Local preview
Open `index.html` in a browser, or serve the folder via any static host such as Netlify or GitHub Pages.

## Founder profile
The founder profile is available at `/about-amos/` and uses a canonical URL on `builtbyamos.in`. Add a real profile image and verified personal social profiles only after they are supplied.

## Notes
- Contact form uses a mailto fallback and clearly explains the next step.
- Example pricing is deliberately editable placeholder pricing.
- Project pages are clearly labelled as design concepts.
